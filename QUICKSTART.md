# Быстрый запуск ScannedDrawings2CAD

Подготовленная локальная копия: Windows x64, Python 3.14. Сервис и модели находятся в этом каталоге; исходный ProjectPractice44Labs для запуска не нужен. Датасеты и результаты прежних запусков не копируются.

Откройте PowerShell в папке проекта и выполните:

```powershell
.\.venv\Scripts\python.exe scripts\start_profiles_v27.py --check
.\.venv\Scripts\python.exe scripts\start_profiles_v27.py --open
```

Также можно запустить `START.ps1` из PowerShell. Адрес: **http://127.0.0.1:8000**.

1. Выберите **«CAD · целые объекты и рамка (эксперимент)»**.
2. Загрузите PNG, JPEG или скан-PDF, дождитесь обработки.
3. Проверьте превью и скачайте DXF нужной страницы.

Остановка — **Ctrl+C** в терминале запуска, либо во втором PowerShell:

```powershell
.\.venv\Scripts\python.exe scripts\start_profiles_v27.py --stop
```

При занятых портах:

```powershell
.\.venv\Scripts\python.exe scripts\start_profiles_v27.py --port 8001 --db-port 55446 --open
```

При первом запуске создаётся новая пустая локальная БД. PostgreSQL может запускаться до 300 секунд. Логи: `artifacts/profile-service-v27/logs/`. Документы и результаты: `artifacts/profile-service-v1/storage/`. Не закрывайте терминал во время обработки.

Копия содержит необходимый runtime, включая три OCR-модели, зависимости сервиса/CV и PostgreSQL. Часть небольших JSON и тестовых файлов сохранена из-за обязательной проверки контрольных сумм действующих профилей. Они не запускают обучение. `runtime-manifest.json` фиксирует состав копии.

Это предварительный демонстрационный сервис: распознавание текста, осей, размеров и слоёв требует проверки. Координаты растра не означают подтверждённый физический масштаб. Текущая `.venv` создана заново для этой машины; для другой машины требуется установка совместимого Python 3.14 и подготовка окружения. Не переносите `.venv` между компьютерами.

В этой локальной копии базовый Python 3.14.6 находится в `artifacts/demo-runtime-v1/python-3.14.6/tools`. Если проект перемещён, обновите пути окружения, находясь в новой папке проекта:

```powershell
.\artifacts\demo-runtime-v1\python-3.14.6\tools\python.exe -m venv --without-pip .venv
```

Затем повторите проверку `--check`. Команда сохраняет уже установленные в `.venv` пакеты; если пакетов нет, потребуется отдельно подготовить зависимости. Не удаляйте папку с базовым Python, пока её использует `.venv`.
